# 两天培训正式课件

`official94/slides.json` 和 94 张 PNG 是经审阅的授课页面。文字用于课件答疑，图片保留图表、流程图和排版。可编辑原稿位于 `output/presentations/航材采购AI智能化实战工作坊_两天94页_正式版.pptx`，课时安排见同目录的 Markdown 文件。

第一天为 1—47 页，第二天为 48—94 页，每天 6 小时。模块建议关联：12—23 页 M01、24—37 页 M02、38—47 页 M03、48—57 页 M04、58—68 页 M05、69—78 页 M06。综合授课页由于当前系统必须指定一个建议模块，暂用 M01；正文已标明仅为可选建议，讲师仍应按实际授课选择实训。

## 导入现有系统

先启动一次系统以初始化数据目录，再停止服务。使用 Python 3 标准库执行：

```sh
python3 scripts/import-courseware.py --data-dir ./data --server-address 127.0.0.1:8080
```

请填写该部署实际使用的数据目录和监听地址。执行后重新启动系统。脚本先备份 SQLite，再替换课件，清空旧课件授权与投影；账号密码、模块授权、练习、咨询和考试数据保留。管理员重新登录后在课堂页面选择授课内容并授权。

Docker 使用命名卷时，应先停止容器，将课件导入该卷实际挂载的数据目录，再启动容器；不要在容器运行期间直接修改数据库。新课件尚未激活，学员看到的页面仍由管理员控制。

仓库仅包含教学课件和模拟示例，不包含本地运行数据库、初始账号密码、API 密钥或学员记录。新增正式学员记录应保存在独立的数据卷中。
