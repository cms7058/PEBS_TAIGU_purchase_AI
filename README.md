# 航材采购 AI 培训与实训平台

正式两天课程共 94 页，第一天 1—47 页、第二天 48—94 页，每天 6 小时。可编辑 PPTX 与课时安排位于 [output/presentations](output/presentations)，保留版式的系统课件包和导入方法见 [courseware/README.md](courseware/README.md)。源码仓库不包含运行数据库、账号密码或 API 密钥；在新服务器部署时请初始化独立数据目录并导入课件。

两天工作坊，10名学员同时在线，管理员统一授课。当前为 **V0.7开发预览**，使用模拟案例及示例试卷。

需求见 [需求规格](docs/requirements.md)，实际范围见 [项目状态](docs/status.md)，接口见 [技术方案](docs/architecture.md)。

## 已实现

- 学员管理：新增、姓名/部门编辑、启用/停用、单人或批量重置密码；最多同时启用10个学员账号。
- 按课件页状态显示按钮，弹窗选择在线/指定学员，回显、增减、清零和全员关闭。
- 独立只读投影，和管理员预览、学员权限分别控制。
- 六个模块的模拟案例、五步引导、CSV空白/示例模板、在线填报、导入校验、计算、复核、草稿/提交/重做。
- 程序计算与规则评分、步骤事件和活动时间估算、讲师改分留痕。
- 管理员专属成绩矩阵、模块均分/耗时/扣分图表、作业时间线及CSV导出。
- 第二天结业考试：题目表单编辑、发布窗口、限时、保存恢复、客观题评分及主观题人工复核。
- SQLite持久化，自动迁移旧版课堂JSON；重启保留作业、评分和考试。
- PPTX原页序文本预览；可选PDF原版式渲染，图片同样受页授权保护。
- 学员采购工作台、六模块固定侧栏、灰显授权状态与独立课件阅读页。
- 浮动助手提供操作指引、术语解释、授权课件文字答疑与来源跳转；无密钥时使用明确标注的本地知识库。原实训提示保留示例回放。十项官方软件体验资源。

从业务模块入口或提交回执点击“查看历史练习”，仅显示该模块记录；详情中的“返回历史列表”和列表刷新保留模块范围。左侧独立“历史练习”入口显示本人全部模块历史。

复盘入口同时使用按钮样式和文字标签区分状态：待整理提交、待管理员回复、管理员处理中、管理员已回复、追问待回复。有回复时提示“查看回复”，追问后显示待答数量；详情页每5秒轻量检查状态，不重置正在填写的访谈或讨论。

## 企业情况访谈、问题提交与管理员回复

学员从“历史练习”打开本人已提交记录，点击“软件利弊与厦门太古适配复盘”：口述／输入 → 保存陈述 → 手工整理 → 核对确认 → 提交。三组通俗问答表辅助填写数据来源、岗位流程、目标约束。学员端取消模型生成、提示词导出与结果导入；旧接口也拒绝这些操作。

管理员进入“问题与复盘”，支持“六大模块 → 学员”和“学员编号 → 模块”两种分类，以及模块、学员、处理状态筛选。打开问题后查看学员提交快照，补充咨询关注点，生成资料复制到ChatGPT，再把中文结果或analysis JSON粘贴为回复草稿。配置AI_BASE_URL、AI_MODEL、AI_API_KEY后，也可由管理员调用后台模型取得草稿；真实服务尚未联调。

草稿和模型结果只对管理员开放，点击“确认返回给指定学员”后才公开给本人。状态为待处理、处理中、已回复，支持保存草稿、保留历次返回记录与处理日志。学员在原复盘页点击“刷新处理状态”查看，不展示评分或他人问题。浮动助手在历史复盘范围只转述管理员已发布回复，不自行生成企业适配结论。

每次提交保存独立快照，重复提交相同内容不新建问题；修改后重新确认和提交形成新记录，原提交及回复保留。已提交练习快照不变，考试期间学员不能访问此功能。旧版已保存的访谈仍可继续整理提交，旧AI结果保留在存储中但不再作为自动答复呈现。

语音由浏览器SpeechRecognition提供，本系统只保存文字；浏览器可能使用厂商在线服务。麦克风、网络和浏览器支持须现场确认，云端需HTTPS；未支持时使用文字或系统听写。[浏览器语音接口说明](https://developer.mozilla.org/en-US/docs/Web/API/SpeechRecognition)。

## 图文报告与持续讨论

管理员可将中文答案或analysis JSON粘贴到回复草稿，点击“预览学员图文报告”核对，再返回给学员。系统按原有章节和【栏目】整理目录、证据、优势、局限、建议、前提、验证指标及待确认项，保留完整原文；已有纯文字回复也会在查看时自动转换，无需重新发布。

流程图使用报告中的五步复盘路径、阶段实施建议；这些是报告结构或建议路线，不冒充企业实际审批流程。有明确“学员陈述基线／目标”依据的耗时数据才绘制比较图，明确标为待核实及未验证；另提供报告栏目数量分布，明确它不是业务绩效或评分。没有数据依据时不补造数值。支持末尾缺少右括号的analysis JSON与转义换行的兼容提取，并提示管理员核对。

学员可对整体答复或具体章节连续追问。追问与回复保存在同一提交下，没有固定轮数上限；每次追问重新进入管理员待处理队列，状态和历史回复保留。管理员先选择回复对象，分别保存各问题的草稿，咨询资料包含原始情况及已发布的讨论历史，核对后返回对应追问。未发布草稿仍仅管理员可见，模型调用额度仍按培训配置控制。

## 回复阅读保护与管理员图文编辑

学员回复与助手转述的管理员答复叠加学员号及查看时间水印，限制正文选择、复制、右键、拖拽、打印与常见保存快捷键。切换窗口或标签页时隐藏正文，返回后点击继续查看；追问表单保留正常编辑、复制和提交。管理员编辑、复制和打印不受该学员阅读限制影响。

这些是浏览器端防传播措施，不是防截屏或DRM保证：无法可靠阻止操作系统截图、录屏、手机拍照、开发者工具或直接读取已授权数据，网页也不能可靠识别截图是否发生。水印是阅读身份提示，不是不可伪造的鉴定证据。页面可见性机制参考[MDN](https://developer.mozilla.org/en-US/docs/Web/API/Page_Visibility_API)；display-capture权限仅控制网页发起的屏幕捕获，[不能把它当作系统截图开关](https://developer.mozilla.org/en-US/docs/Web/HTTP/Reference/Headers/Permissions-Policy/display-capture)。

管理员详情自动显示与学员相同的图文预览，展开章节点击“编辑本部分”可修改标题、栏目及正文。完成编辑后点击“保存图文编辑为草稿”，重新生成图表与流程，再明确返回学员；也可通过“保存草稿”保存当前图文修改。未发送的草稿不改变已发布版本，历史回复保留。数值图表与流程取自对应正文，修改效率指标或阶段内容后保存即可更新，不单独伪造无依据的图表数据。

## 本地启动

需要Go 1.24+。当前任务工具链位于tmp/toolchain/go/bin/go，脚本也可识别。

```sh
cp .env.example .env
# 编辑.env，填写至少16字符的BOOTSTRAP_ADMIN_PASSWORD。
./scripts/dev.sh
```

访问 http://localhost:8080 选择身份。管理员入口为 /admin，学员入口为 /learner；两个入口独立校验账号身份、保存会话和退出，可在同一浏览器的不同标签页同时使用。管理员账号为admin，密码来自环境配置。首次启动生成data/bootstrap-credentials.csv，包含10个学员各自的随机初始密码，由管理员分发。改密后初始密码失效，需要重新登录。

开发预览使用独立的tmp/full-data，包含自动化验证生成的模拟成绩。正式培训请使用新的DATA_DIR，不把预览成绩当作实际学员记录。

## 学员与密码管理

管理员登录后选择“学员管理”，编辑姓名及部门/小组，新增账号，或启用/停用账号。最多同时启用10人，换班可先停用原账号再新增；停用立即退出账号并清除课件及实训权限，历史数据保留，重新启用后由讲师重新开放权限。

学员密码支持6–200字符，新增、单人重置和学员自行改密采用相同最低长度。单人重置可指定新密码，留空自动生成；批量重置每人生成独立随机密码。新密码仅在成功结果弹窗中显示，支持复制，关闭后不可查询。重置会使旧密码与所有旧会话失效。管理员自己的密码仍在“密码”页面修改。

## 课件与投影

学员从左侧“课堂课件”进入阅读，支持已授权页列表、翻页、跟随讲师和全屏。讲师切页不会打断业务填报。六个业务模块始终显示在侧栏，未激活灰显禁用，后端同样检查权限。工作台统计只来自本人最近练习，不展示管理员评分。

新导入的PDF使用pdftotext逐页提取文字供助手答疑；图片页没有OCR，无法提取时明确说明。旧PDF需重新导入或由管理员补充页面文字，才能用于正文答疑。

需要保留字体、排版和图片时，从PowerPoint导出PDF再上传。PDF渲染需要pdftoppm及pdfinfo；本机已经验证。PPTX直接导入只提取文本和原页序，不保留原版式、图片、动画或视频。

替换/编辑课件清空课件授权与当前投影，保留练习。管理员打开独立投影窗口，在操作系统扩展显示模式下移到大屏并全屏。给个别学员授权不会自动改变大屏。关闭页面后投影等待、学员失权，实训独立控制。

## 实训和评分的范围

进入模块先显示任务入口：未开始时可开始实训，有草稿时可继续，已提交时可开始新一轮或查看上次回执。新一轮从阅读任务开始，历史作业与评分保留；进入任务入口本身不会创建作业。

本版采用明确的教学模型与结构化数据：计划缺口、报价约束与总成本、供应商评分/集中风险、订单延期、固定交期下的库存参数、AOG可行方案比较。CSV字段和单位在页面说明。

固定rule-v1量表：步骤20、数据20、计算25、决策15、表达10、效率10。表达规则分仅检查篇幅、案例编号和约束词，语义质量由讲师复核，没有伪装成AI语义评分。重做保留历史，报告取最近一次尝试；未提交不计入均分。

活动时长由服务端事件及15秒心跳估算，长时间断线、后台无活动和AI等待不计为连续操作。这不是屏幕监控，不能精确还原每次鼠标操作。

待深化：非结构化报价/邮件/扫描件解析、可配置评分量表、更多预测优化模型和跨模块结果传递。当前标准表格格式为CSV，XLSX后续扩展。

## AI配置

右下角助手跨业务页面保留当前会话，退出即清空。配置模型后支持带短会话上下文的对话；未配置时明确使用本地操作/术语知识库与授权课件摘录，不宣称在线模型已联通。原实训AI提示仍显示示例回放。

助手与原实训提示共享并发和调用额度。服务端仅选择本人权限内课件，排除考试答案、评分及他人作业；考试期间暂停答疑。在线答复返回前重新校验权限，课件已撤权时不再显示答复。

配置AI_BASE_URL、AI_MODEL、AI_API_KEY。BASE_URL应包含服务商基础路径（例如/v1），不含/chat/completions。密钥只在后端使用。

默认100次培训调用额度、最多2个并发，AI_MAX_CALLS可配置。额度包含已经预留但失败的尝试，防止自动重试重复消费。未配置时明确回放示例；协议已用模拟服务测试，真实服务商尚待密钥联调。

兼容接口参考 [官方Chat API文档](https://developers.openai.com/api/reference/resources/chat)。具体服务商需支持相应请求字段。

## Docker部署

```sh
docker compose up --build -d
docker compose exec training /server --healthcheck
docker compose cp training:/data/bootstrap-credentials.csv ./data-bootstrap-credentials.csv
```

默认RUNTIME_TARGET=runtime-core，为不含转换工具的核心镜像。需要PDF原版式渲染，在.env改为RUNTIME_TARGET=runtime-pdf后重建，运行镜像会增加Poppler。

默认绑定127.0.0.1:8080。云端通过HTTPS反向代理开放，设置COOKIE_SECURE=true。AI环境变量传入后端，数据保存在命名卷。

当前机器没有Docker，配置已准备但未实际构建和启动容器，不能将二进制大小当作完整镜像体积。

## 停机和备份

```sh
docker compose stop
docker compose cp training:/data ./classroom-backup
docker compose start
```

停止后备份整个目录，包括数据库及WAL/SHM、课件和初始凭证。不要用down -v删除需要保留的数据卷。恢复到空数据目录/卷后启动，密码与作业保留，会话需重新登录。

## 企业实训、字段与历史复盘（V0.3）

学员界面统一为浅蓝色。采购助手入口可拖动，对话框可通过标题栏独立拖动；支持方向键移动及“归位”。

每个模块先选择分源采集、人工填报或基础样例。按通用MRO／ERP／WMS／SRM／QMS分层提供三份来源格式及24行仿真记录；可上传CSV、扁平JSON或粘贴导出数据，记录系统、业务对象、主键、采集人和截至时间。校验重复主键和缺失关联，不声称已经连接企业内部API。

本人每模块可增加最多20个文本、数字、百分比、布尔或日期字段，设置用途及必填性。支持映射和手工填报，定义在新一轮沿用，数据按每次尝试快照保存。补充字段不自动改变核心公式，影响计算须映射到标准输入或使用已支持的场景参数。

六模块提供各自的需求倍率、交付时限、供应商评分权重、库存服务系数等参数；调整后清除旧结果，评分按本次参数重算。每一步显示对应厂商软件模块、官方说明及试用／演示渠道，体验账号是否包含具体功能仍需核实。

“历史练习”只展示本人数据和过程，不含管理员评分。已提交记录可开启分步骤的软件利弊及厦门太古适配复盘；草稿不可开启。助手仅在相应历史上下文提供适配答疑，离开后隐藏这部分会话，考试期间暂停历史查看。模块关闭不删除既有练习。

软件、采集架构、官方来源及对接边界见 [软件映射说明](docs/software-mapping.md)。实际企业系统名称、字段字典、API与授权未提供，当前实现为导出快照采集和人工录入；适配建议明确为待企业验证的方案。
