# 构建与验收计划

版本：2026-10-27。范围依据 requirements.md。

当前已形成V0.2开发预览：授课控制、SQLite、六个基础案例、规则评分和图表、AI兼容接口及基础考试均有实现。以下为完整交付分解；深度功能和待办以status.md为准。

## 阶段 P0：真实授课控制基础

- Go 工程、静态前端、配置示例、Dockerfile 和 Compose。
- 真实登录/退出、管理员与 10 名学员角色隔离。
- 示例课件、独立投影端、学员端，使用同一服务端状态。
- 点击 PPT 页 → 状态相关按钮 → 学员弹窗 → 确认；支持完整名单替换和逐页全员关闭。
- 开放/结束模块入口；不把模块介绍页视为实训完成。
- 临时文件存储仅用于验证基础流程；正式建库在 P1 替换，保持数据访问接口稳定。

P0 验收：A01–A10。当前构建先完成这一阶段的可运行切片。

## 阶段 P1：数据与教学工作流

- SQLite 数据库、迁移、案例/模板版本、草稿与提交状态机。
- PPT/PDF 导入与可选转换流程；提供失败提示和回退方式。
- 模板下载、字段字典、上传预检、行列错误定位。
- 操作事件、计时、评分规则及管理员操作审计。

## 阶段 P2：六个实训模块

按报价比选、库存优化、AOG 综合演练、需求计划、供应商风险、订单交付的顺序开发，但首版交付覆盖六个。

每个模块达到：有案例、有模板、有引导、有可验证计算/分析、有提交、有评分证据。模块结果可串联且保留版本。

## 阶段 P3：AI、评分与统计

- API 适配、并发队列、额度、失败回放/待评状态。
- 确定规则评分与 AI 辅助评价，讲师复核。
- 管理员专属图表、明细下钻和备份导出。

## 阶段 P4：结业考试与部署验收

- 题库、试卷快照、限时/保存/交卷/评分、逐题分析。
- 正式课程题目在收到 PPT 后录入并由管理员审核。
- 10+1 人负载验证、权限测试、断线/重启恢复、Docker 镜像测量及云端部署演练。

## 验收场景

| ID | 场景 | 通过条件 |
| --- | --- | --- |
| A01 | 登录与角色 | 无登录返回 401；学员不能读管理接口或他人作业；退出后会话失效 |
| A02 | 首次激活 | 默认按确认时在线名单激活；未选择离线学员不获授权 |
| A03 | 调整名单 | 8 人改为 3 人，剩余 5 人立即失权；可新增、清零、取消 |
| A04 | 全员关闭 | 包含离线学员的该页授权全部撤销，其他页/实训不变 |
| A05 | 页面不可绕过 | 无授权学员直接请求该页接口也被拒绝 |
| A06 | 投影隔离 | 学员授权不改投影，暂停不改学员权限；关闭投影页进入等待 |
| A07 | 重连恢复 | 断线期间被撤销，重连不得恢复旧权限 |
| A08 | 版本冲突 | 两个管理页面基于旧版本保存，后保存者得到冲突并重新载入 |
| A09 | 停机恢复 | 重启后授权、课件与提交数据保留；写入失败不报告成功 |
| A10 | 学员模块入口 | 未开放不得进入，结束后不接受新操作，已保存数据保留 |
| A11 | 模板导入 | 空白/示例均可下载；非法字段给出行列错误，失败不部分入库 |
| A12 | 报价实训 | 模板与文本报价可复核；币种/单位统一；计算正确且能追溯原文 |
| A13 | 计划实训 | 计划或交期变化后缺口/采购建议一致更新，保存参数与依据 |
| A14 | 风险实训 | 权重总和检查、风险证据、集中度计算和保障措施均可查看 |
| A15 | 交付实训 | 邮件中的延期/数量异常能被复核、记录并关联任务 |
| A16 | 库存实训 | 样例可手工核算，参数变化反映到风险与成本；不适用假设被提示 |
| A17 | AOG 实训 | 不合条件方案不能静默排第一；时间、成本、风险及人工复核可查 |
| A18 | 计时评分 | 系统等待不算学员慢操作；重做保留；AI 失败进入待评 |
| A19 | 统计权限 | 学员直接访问报告/成绩汇总接口被拒绝；图表正确区分待评与零分 |
| A20 | 考试 | 第二天管理员开放；服务端限时、恢复草稿、幂等交卷；答案不泄露 |
| A21 | 负载 | 10 学员+1 管理员；普通 API 和授权传播达到需求目标，AI 请求受限流 |
| A22 | Docker | 能构建启动、健康检查、备份恢复；测量核心镜像体积并记录环境 |

## 完成定义

每阶段提交可运行代码、相关测试和已知限制；README 说明实际支持范围。只有 A01–A22 及课程内容确认完成后，才能称为整个系统可交付。
