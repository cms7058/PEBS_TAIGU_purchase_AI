# 航材采购 AI 培训与实训平台需求规格

版本：V1.0，2026-10-27。状态：根据讨论形成的构建基线；下文标注的建议参数尚未成为最终课程规则。

## 1. 项目目标与使用边界

为厦门太古航材采购 AI 工作坊提供统一的两天教学环境，覆盖授课、引导式实训、过程采集、评分、管理员统计及第二天结业考试。

- 10 名学员同时在线，另设管理员；管理员兼任讲师。
- 培训期间按需启动，课后备份、停止，下次可恢复或重置。
- 六个业务模块全部自建，外部厂商试用作为独立可选资源。
- 浏览器访问，Docker 部署到云服务器。优先响应速度、较小部署体积和易维护。
- 允许调用外部大模型 API。密钥只存服务端。
- 先使用标注清楚的模拟数据；真实脱敏资料可后续导入。此项为构建默认值，用户尚未提供数据。
- 商业软件的完整界面、专有算法及行业市场数据库不属于复刻范围；实现对应业务实训能力。

## 2. 用户和权限

| 角色 | 权限 |
| --- | --- |
| 管理员 | 管理学员、PPT、页面授权、实训、案例模板、评分标准、考试、报告及系统配置 |
| 学员 | 登录后查看对本人激活的页面，操作对本人开放的模块，保存并提交作业，参加已开放的考试 |
| 投影显示端 | 仅展示讲师指定的课件或等待画面，不包含管理员控制、答案、成绩和学员信息 |

权限在服务端校验，禁止仅靠前端隐藏按钮。学员只能读取和操作本人的练习；管理员统计和详细评价仅管理员可查看。学员端显示引导、输入校验、保存/提交回执；分数是否单独向本人发布，暂不开放，留待另行确定。

### 2.1 学员与密码管理（补充）

管理员可新增学员、编辑姓名与部门/小组、启用/停用，以及单个或批量重置密码。最多同时启用10个学员账号；停用立即使会话失效并关闭其课件/实训权限，保留历史记录。重置支持单人指定密码或随机生成，批量每人独立随机；新密码只在操作结果显示，管理员自己的密码单独修改。

## 3. 管理员授课控制

### 3.1 已确认的交互

1. 点击 PPT 缩略页，更新预览，在固定操作区按页面状态展示按钮，不自动发布。
2. 未激活页显示“激活页面”；已激活页显示“调整激活学员”“关闭此页”；已关闭页显示“重新激活页面”。
3. 点击激活/调整按钮后打开学员选择弹窗。
4. 首次激活默认选择发布时的所有在线学员，也可选择单个、多个或全班账号。
5. 调整已激活页时回显实际激活名单。保存采用完整名单替换，可新增、减少或清零，不能只叠加。
6. 弹窗显示当前人数、保存后人数、新增及移除人数。取消、关闭弹窗或 Escape 均不改变权限。
7. 同一弹窗可展开选择关联实训；调整 PPT 人数默认不改变实训权限。
8. 页面列表持续显示未激活、已激活及人数、已关闭状态。

### 3.2 页面授权规则

- 一页可激活给多名学员，一名学员可查看多页已获授权内容。
- 新增授权后可将学员引导至该页；已有授权调整时保留其当前查看位置。
- 取消某学员授权后，该页从其列表中移除；正在查看此页则进入等待画面。
- “关闭此页”确认后撤销所有学员授权，包括离线学员，不受弹窗的勾选范围限制。
- 已激活的其他页面保留原授权。重新登录、刷新、断线重连后读取最新服务端状态。
- 关闭课件页不自动结束实训；已保存数据和提交记录保留。
- 并发控制时使用版本检查，旧页面不能无提示覆盖更新后的权限名单。
- 页面关闭后在线查看被撤销；已经自行截图等外部副本不受系统控制。

### 3.3 在线状态

以已登录且近期有心跳的会话计算在线人数，建议心跳 15 秒、超过 45 秒标为离线。正式阈值可配置。默认“所有在线学员”在确认时按服务端在线名单取快照；以后上线的学员不自动加入，管理员可调整。多标签页不重复计人数。

## 4. PPT 与投影

补充：学员登录后进入采购管理系统风格的工作台，六模块固定为左侧菜单，未激活灰显禁用并标明状态；接口同样校验。课件放在独立“课堂课件”菜单，与业务界面统一风格，讲师切页不打断填报。

- 管理员上传课件、浏览缩略图和预览，保留源页码；正式 PPT 尚未提供。
- 第一阶段支持标准化课件页面包/示例页面。正式导入优先支持 PDF；PPTX 通过可选转换容器生成图片/PDF，转换状态和失败原因可查看。源文件与转换结果建立版本关系。
- 静态转换不承诺保留动画、嵌入媒体和交互；如最终课件需要这些效果，使用原生 PowerPoint 放映，并另行确定是否需要自动同步。
- 为投影建立独立显示路由/窗口，电脑使用扩展显示，将投影窗口移至大屏并全屏。
- 管理员预览页、投影页、学员授权页三者独立。
- “投影当前页”“暂停投影”由管理员控制。暂停时显示等待画面。
- 给个别学员授权不改变投影；关闭正在投影的课件页则大屏进入等待画面。
- 投影端与云端断线时明确提示连接异常，重连后恢复服务端状态。
- 正式实现使用仅能读取投影画面的凭证，不在投影窗口暴露管理权限。

## 5. 六个业务实训模块

### 5.1 统一操作流程

学习目标 → 案例说明 → 模板与示例 → 上传/填报 → 数据检查 → 引导式操作 → 分析与决策 → 保存/提交 → 管理员评价。

每一步包含说明、完成条件、错误定位及必要示例。支持返回修改、草稿保存、断线恢复、再次提交和讲师重置。关键复核步骤必须由学员操作，不能通过一次 AI 调用直接跳过整个练习。管理员可按教学进度开放、结束模块。

| 模块 | 输入 | 主要操作 | 输出与评价重点 |
| --- | --- | --- | --- |
| M01 需求预测与采购计划 | 维修任务、历史消耗、库存、在途、交期 | 区分计划/非计划需求；比较基准预测；调整计划、交期；计算缺口及采购时点 | 需求预测、缺料清单、采购建议；评价方法、假设及供需对齐 |
| M02 寻源询价与比价 | 三家报价、RFQ、币种/汇率、运费与附加条件 | 提取原文并复核；统一件号/件况/单位；计算总成本；综合比较 | 可追溯报价比较表及推荐理由；识别缺失证书、交期与价格陷阱 |
| M03 供应商管理与风险 | 资质材料、交付/质量记录、采购份额 | 准入核查；配置评分权重；识别集中度和单一来源；制定保障策略 | 风险清单、评分卡、保障方案；评价证据、权重及风险响应 |
| M04 订单执行与交付 | 采购订单、模拟往来邮件、物流事件 | 识别承诺交期变化；核对数量/日期；关联维修需求；起草催交 | 订单时间线、预警及催交草稿；评价异常识别和处置顺序 |
| M05 库存与数学优化 | 消耗、库存、交期、服务目标、成本参数 | 数据分型；计算再订货点/安全库存；调整参数；比较策略 | 补货参数、缺货风险/库存成本图表；评价计算及适用假设 |
| M06 AOG 紧急采购 | 紧急需求、候选库存/报价、运输时刻与成本、证书条件 | 比较购买、借件、交换、调拨；判断可行性；安排人工复核 | 时间/成本/风险对比及决策记录；评价关键条件、时间顺序及解释 |

航空专业字段贯穿业务：件号、序列号（如适用）、件况、适用机型、证书类型/编号、追溯状态、数量、计量单位、需求日期、币种、交期、报价有效期、交换/返芯条件等。适用性和证书审核采用课程规则及人工复核，不把 AI 文本当作真实放行结论。

模块进入时先显示任务入口，明确区分首次开始、继续草稿、开始新一轮与查看上次回执。不得将“进入实训”直接解释为查看已提交记录；新一轮须从阅读任务开始，历史作业及评分保留。

### 5.2 关联案例

用同一套模拟维修任务串联需求、缺料、询价、供应商、订单、库存及 AOG。模块可独立练习，也可传递结果；传递时保存来源和版本，避免学员改动上游后静默覆盖下游已提交结果。

## 6. 模板与数据标准

- 每个上传或填报入口必须提供空白模板、已填写示例及字段字典。
- 表格首选 XLSX，并提供 UTF-8 CSV；表单与文件使用同一验证规则。
- 字段字典说明必填、数据类型、允许值、长度、单位、日期/时区、精度和唯一性。
- 明确币种，不把不同币种金额直接求和；汇率记录来源日期，教学汇率标为模拟。
- 导入先预检，报告行/列/字段及修复建议，确认后入库；失败不产生部分隐式数据。
- 文档输入先支持文本型 PDF、TXT/邮件文本和标准报价表；扫描件 OCR 为可选能力，若未配置须提示并提供替代格式。
- 所有样例标注模拟；模板含版本，案例锁定模板版本。
- 建议单文件 10 MB、表格 5,000 行作为初始限制，实测后调整。

模板清单：维修计划、历史消耗、库存与在途、供应商主档、资质材料清单、报价、采购订单、物流事件、成本参数、AOG 需求/候选方案、分析报告及考试题目导入模板。

## 7. 过程采集与评分

### 7.1 记录内容

记录任务开始、步骤进入/完成、上传与校验结果、关键字段修改摘要、计算参数、AI 请求、人工复核、保存、提交、管理员重置等事件。每条事件关联学员、案例、尝试次数、步骤、服务端时间、结果版本。服务端确认业务动作，不能只依赖前端自报事件决定得分。

### 7.2 计时

分别记录任务总历时、有效操作、暂停/离开、系统处理/API 等待及重做次数。以心跳/活动窗口估算有效时长，展示计时口径；网络断线与服务等待不作为慢操作扣分依据。时区统一显示 Asia/Shanghai，服务端保存 UTC。

### 7.3 评分建议

| 维度 | 初始建议权重 |
| --- | ---: |
| 操作步骤与规范 | 20% |
| 数据质量 | 20% |
| 分析方法与计算 | 25% |
| 决策及解释 | 25% |
| 操作效率 | 10% |

以上权重待讲师确定，可按模块配置且总和为 100%。必做步骤、数据与计算使用确定规则；开放分析由 AI 根据量表辅助评分。评分需引用作业中的证据，注明评分器/模型/量表版本。AI 失败时状态为“待评”，不默认给零分；允许人工评分。讲师调整须保留原分、调整分及原因。

明确规则类问题可即时形成评价；提交后生成管理员可见的完整评分报告。重做保留所有尝试，最终成绩取最后一次/最高一次/指定一次的规则由讲师配置，默认待定，不悄悄覆盖。

## 8. 管理员专属统计页面

报告以网页指标、图表与明细展示，不发送邮件、企业微信或钉钉。

- 在线、待开始、进行中、已提交、待评分和已完成状态。
- 学员 × 六个模块进度矩阵、分项得分、分数分布及重做次数。
- 步骤耗时分布，区分有效操作与系统等待。
- 常见错误、扣分原因、模块薄弱环节及学员操作时间线。
- 结业考试成绩分布、通过率、题目正确率/得分率和逐题分析。
- 缺失数据标为未开始/未提交/待评，不混同零分；平均分明确分母。
- 图表可下钻到证据和作业版本。管理员可导出明细及汇总供备份；导出不是自动外发报告。

## 9. 第二天结业考试

- 仅第二天安排一次正式结业考试，第一天无考试。
- 题目根据最终课程 PPT 编制；课件未到位前只建设题库/考试能力，示例题不作为正式试卷。
- 支持客观题、案例分析及实操题，管理员审核题目、分值、答案、解析、对应知识点/PPT 页后发布。
- 配置开放窗口、考试时长、学员名单和通过线。建议参数必须由管理员在发布前确认。
- 服务端计时、自动保存、恢复作答、到时交卷；不依赖浏览器时间判断截止。
- 客观题自动评分，主观题辅助评分与人工复核；重复交卷幂等。
- 考试期间关闭实训提示/标准答案入口，草稿接口和学员接口不得返回答案。
- 题目/选项随机需保证每名学员刷新后顺序稳定；考试发布后保留试卷快照。
- 管理员可延时、作废或安排补考，操作留痕；正式补考规则另定。
- 结业成绩是否与实训加权合成及权重待定，未配置前分开展示。

## 10. 软件试用资源库

按模块关联软件，展示名称、功能、官方链接、体验类型、账号申请条件、公开期限、限制及核查日期。

体验类型必须区分：免费试用、受限免费账户、产品导览、预约演示、待确认。记录“官方公开信息”和“实际账号验证”两种证据；无实际账号的不得标为已验证可用。由用户自行注册，系统不收集第三方密码。

## 11. AI 与计算

- AI 用于报价/邮件提取、解释、引导建议和开放题辅助评价。
- 数值计算、权限、截止时间、评分规则由程序处理，不用模型输出直接替代。
- 统一模型适配层，可配置服务商、模型、地址和超时，密钥只在服务端环境/受保护配置中。
- 初始建议最多 2 个 AI 请求并行，其余排队；管理员设置全班费用/调用额度。幂等、防重复提交、重试有上限。
- 保存源文与提取字段对应关系；低置信度或缺失项要求人工确认，不能补造证书、价格或交期。
- 未配置 API 时提供明确标注的样例回放，不能伪装为实时 AI 结果。
- 上传文件内容视为业务数据，文档中的指令不得改变系统规则、泄露凭证或调用任意工具。

### 11.1 浮动助手（补充）

补充：浮动助手可收起/展开，跨系统页面说明操作、解释术语、解读本人已授权课件，支持短会话和来源跳转。后端筛选可引用内容，考试中暂停，退出清空；无模型时明确标注本地知识库。PDF文字需导入时提取，图片页不承诺OCR。

## 12. 部署、性能与恢复

- Go 后端，轻量静态前端，模块化单体。正式数据层使用 SQLite，单实例部署适配 10 人课堂；复杂并发或扩展后再评估 PostgreSQL。
- 应用、数据卷、可选课件转换服务通过 Docker Compose 编排，上传附件与数据库持久化。
- 建议起步 2 vCPU/2 GB 内存（不含本地大模型和课件转换），最终以压测为准。
- 待验收目标：10 名学员 + 1 管理员，普通 API p95 < 300 ms（服务端，不含公网和 AI），权限变更在线端 2 秒内反映；课堂状态可先使用 1 秒轮询，后续按需要换 SSE。
- 核心应用压缩镜像暂以 ≤100 MB 为目标，不含附件、数据库、模型及转换镜像，构建后测量；这不是已达到的结果。
- 提供存活/就绪检查、明确的初始化配置、备份及恢复步骤、失败回滚方法。
- 停止服务不丢数据；恢复后课件授权、作业和成绩保留，会话可要求重新登录。
- 使用 HTTPS，密码安全哈希，会话 HttpOnly cookie，管理操作鉴权和审计；不内置可公开部署的固定密码。

## 15. 企业实训升级与历史复盘（新增）

1. 学员界面和浮动助手采用浅蓝色普通业务工具风格，入口和对话框可独立拖动，提供归位。
2. 六模块按企业系统分层展示数据采集路径，支持用户导出快照、字段映射、主键关联及人工填报。实际企业系统未提供时使用明确标注的通用架构，不声称已经打通私有接口。
3. 每个学员可独立扩展字段，保存类型、单位、用途、必填和来源；不能覆盖核心字段，定义与数据随练习保留。场景参数影响实际计算与评分。
4. 每步骤展示对应软件模块、字段及官方试用／演示渠道；说明教学映射与原厂真实字段、许可的区别。
5. 历史练习保留本人每次尝试的只读数据、字段、来源、参数、步骤和结论，不展示管理员评分。
6. 只有在查看已提交历史记录时开放步骤利弊和厦门太古适配复盘，草稿禁用；先收集并确认企业实际情况，之后才分析，助手遵守相同范围。


## 16. 企业访谈提交与管理员集中复盘（V0.5，取代原学员直接分析）

1. 学员在本人已提交练习的历史复盘内口述或填报现有系统、功能、数据、流程、问题、目标、待确认事项，使用可编辑问答表辅助填写。手工整理、核对确认后点击“提交”，不由AI直接返回企业建议。
2. 管理员增加“问题与复盘”，提供六大模块分类和学员编号分类，可交叉筛选模块、学员和处理状态，查看原始陈述、确认内容及对应练习次数。
3. 管理员根据已提交快照生成ChatGPT咨询资料、补充关注点；支持外部咨询后粘贴中文或analysis JSON，也保留配置后台模型后咨询的入口。模型结果先保存为管理员草稿，不自动发送。
4. 管理员核对后明确返回给当前学员；学员在本人记录查看状态与回复。草稿、管理员补充问题和内部处理日志不向学员公开。
5. 保留待处理、处理中、已回复状态，管理员处理与返回留痕；重复相同提交不重复建单，修改后形成新提交，原快照与历次回复不被覆盖。
6. 服务端禁止学员访问管理员接口，以及原直接生成／提示词导出／结果导入接口。考试期间禁止学员查看。管理员回复不包含评分，评分仍走管理员专属统计。
7. 修复历史数组缺省导致的map异常；静态脚本使用版本参数和no-store防止页面与API版本混用。保留原有账号、练习和访谈数据。


## 17. 结构化图文回复与多轮讨论（V0.6）

1. 管理员答案按原文问题、章节及栏目转换为可导航图文报告，保留原文，发布前可预览。历史纯文字回复无需重新发送即可结构化展示。
2. 流程图明确区分复盘步骤、建议实施阶段与企业真实流程；未知审批关系不编造。图表带数据来源与性质说明，计划目标不当作实际效果，模拟记录占位值不作为绩效。
3. 学员可以从报告任一章节发起追问、补充企业事实或讨论建议；同一提交支持持续多轮，不强制新建练习或重新填写访谈。提问前需有管理员首次回复。
4. 管理员按原模块与学员分类管理追问，在同一问题详情查看完整记录、选择回复对象、保存各自草稿和发布结果。咨询上下文包含原始确认内容及历次公开讨论。
5. 追问重新进入待处理队列，发布对应回复后标记已答；仍有未答追问时保持待处理。保留全部问答、来源和时间，重启不丢失。
6. 学员仅能向本人记录提问，不能读取管理员草稿、他人讨论或绕过管理员直接请求模型；考试期间禁止追问，重复网络提交通过请求标识去重。


## 18. 学员回复阅读保护与管理员编辑（V0.7）

1. 学员回复及助手转述的管理员回复使用身份/时间水印，限制复制、右键、拖拽和打印，离开窗口/页面时隐藏，回到页面后手动继续查看；追问输入不受影响。
2. 明确说明浏览器不能保证禁止系统截屏、录屏或拍照，不将blur、PrintScreen等事件认定为已检测或拦截截图，不伪造截图审计记录。
3. 管理员使用相同报告渲染器预览，逐章节修改标题、栏目和正文，保存为草稿后更新图表、流程，核对再返回；未发送的修改只对管理员可见。
4. 管理员编辑与复制保持可用，已发布历史版本保留，学员端只读。
